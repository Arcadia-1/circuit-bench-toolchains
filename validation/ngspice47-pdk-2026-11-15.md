## IHP SG13G2 with VACASK stays on 0dedf26

VACASK 0.3.4's `sg13g2tovc` opens a fixed list of IHP model libraries,
including `sg13g2_hbt_mod_mismatch.lib` and `resistors_mod_mismatch.lib`.
IHP folded both into the main libraries (dev commits 7b10545e, 2026-09-17, and
1d12af5a, 2026-10-18). Converting each IHP commit in the VACASK 0.3.4 base:

| IHP commit | Result |
| --- | --- |
| dc66e8e1 (dev, 2026-09-16) | converts |
| 7b10545e (dev, 2026-09-17) | fails: `sg13g2_hbt_mod_mismatch.lib` not found |
| 94764388 (dev, 2026-10-07) | fails: same |
| 1d12af5a (dev, 2026-10-18) | fails: `resistors_mod_mismatch.lib` not found |
| e73adb4 (main, 2026-11-10) | fails: same |

On main the only snapshot after `0dedf26` is `e73adb4`, so the IHP VACASK
image keeps `0dedf26` until a VACASK release supports the new layout. Its MOS
models equal those of `e73adb4`; HBT, resistor and diode statistics differ.
