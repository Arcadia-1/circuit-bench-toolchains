# GF180 ngspice image validation, 2026-11-12

Candidate: `docker/ngspice-gf180.Dockerfile`, built locally as
`circuit-bench-gf180-ngspice:rc` with rootless podman 4.9 on an x86-64 host.

## Build

- Base: `ghcr.io/arcadia-1/circuit-bench-ngspice@sha256:0fbd3883b7c333eba55554bb14953b414e5a0ff7e7455feb6c8cec08575f91e4`
  (the published policy-free `2.0.8` base, ngspice 46).
- Models: open_pdks GF180MCU snapshot `792ef67037d74c8c51811eab3ce23cf793491296`,
  `common.tar.zst` from fossi-foundation/ciel-releases, sha256
  `1342fe46866de6a3f1d8c3edb3193dafa4c3cf955cb987a17791b2287c41e39d`.
  Only `gf180mcu{A,B,C,D}/libs.tech/ngspice/` is kept; the four variants'
  ngspice files are byte-identical.
- Build time 23 s (base cached); image size 284 MB.

It loads every typical-corner section and exercises 3.3 V and 6 V MOS, the
`ppolyf_u` resistor, the `cap_mim_2f0_m4m5_noshield` MIM capacitor, the
`pnp_10p00x10p00` vertical PNP and the `diode_pd2nw_03v3` diode.

## Consumer regression

A set of five third-party GF180 analog task packages (bandgap design and
repair, LDO design and repair, crystal-oscillator repair) had been validated on
a task-local ngspice 47 build of the same GF180 snapshot. Their model files are
byte-identical to this image's. A thin layer on the candidate recreated the
task's model path, and the unmodified task verifiers were rerun on 18 cases:
five reference solutions, the starters, and twelve negative submissions.

- All 18 outcomes and rewards matched the ngspice 47 results exactly.
- Reference metrics matched to the printed precision; the largest relative
  difference was in a 1e-12 V startup residual (numerical noise).
- The crystal-oscillator reference run took 467 s, the others under 3 s.

The image therefore carries the GF180 tasks without recalibration.
