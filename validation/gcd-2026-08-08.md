## Dynamic verification

The fixed-seed Verilator regression ran 562 directed and pseudo-random cases,
including zero operands, equal operands, both operand orderings, Fibonacci
pairs, long subtraction cases, single-bit patterns, complements, and response
backpressure.

| Metric | Result |
| --- | ---: |
| Functional checks | 562/562 pass |
| Line coverage | 100.0% (9/9) |
| Bit toggle coverage | 100.0% (1754/1754) |
| Branch coverage | 95.8% (23/24) |
| Expression coverage | 84.6% (11/13) |

The three unhit points are structural: `req_rdy == 0` in IDLE,
`resp_val == 0` in DONE, and the controller's illegal/default state. Reaching
them dynamically would require forcing an illegal internal state or changing
the DUT.
